📘 What is Linear Search?

Linear Search is a simple search algorithm that checks each element in the list one by one until the target value is found or the list ends. It works on both sorted and unsorted arrays.

🧠 Algorithm:

for i = 0 to n-1:
    if arr[i] == target:
        return i
return -1
