📘 What is Exponential Search?

Exponential Search works by finding a range where the target may exist using exponential jumps and then applying binary search within that range.

🧠 Algorithm:

if arr[0] == x: return 0
i = 1
while i < n and arr[i] <= x:
    i = i * 2
BinarySearch(arr, i/2, min(i, n-1))
