Bubble Sort

Definition: Bubble Sort is a simple comparison-based algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.

Importance: While not efficient for large datasets, Bubble Sort helps in understanding sorting principles and debugging. Best case is O(n) if the array is already sorted.

Real-life use:
1. Educational tools and algorithm learning
2. Basic data preprocessing
3. Systems with small datasets
4. Sorting animations in visualizers

BubbleSort(arr):
  for i from 0 to n-1:
    for j from 0 to n-i-1:
      if arr[j] > arr[j+1]:
        swap arr[j], arr[j+1]
