Searching

Definition: Searching is the process of finding a specific element in a collection of data.

Importance: Efficient searching improves performance in databases, applications, and systems.

Key Terms: Linear Search, Binary Search, Search Space, Time Complexity

Real-life Applications: File explorers, search engines, autocomplete suggestions.

Linear Search

Simple, checks each element one by one.

Binary Search

Divide and conquer on sorted arrays.

Interpolation Search

Predicts where to search in uniform distributions.

Exponential Search

Efficiently finds range, then binary search.

Jump Search

Skips fixed steps, then performs linear scan.
