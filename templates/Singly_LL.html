📘 What is Singly Linked List?

A Singly Linked List is a linear data structure in which each element (node) contains a value and a reference (link) to the next node in the sequence. The last node points to null. 

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

head = None

# Insert at end
new_node = Node(data)
if head is None:
    head = new_node
else:
    temp = head
    while temp.next:
        temp = temp.next
    temp.next = new_node
