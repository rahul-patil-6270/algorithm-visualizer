Quick Sort

Definition: Quick Sort is a divide-and-conquer algorithm that selects a pivot and partitions the array into two subarrays, recursively sorting them.

Importance: One of the fastest sorting algorithms in practice, with average-case time complexity O(n log n). Not stable but very efficient on large datasets.

Real-life use:
1. Database sorting
2. File system operations
3. Numerical computations
4. Search engine indexing
5. Compiler optimizations

Algorithm (Pseudocode): quickSort(arr, low, high): if low < high: pi = partition(arr, low, high) quickSort(arr, low, pi - 1) quickSort(arr, pi + 1, high) partition(arr, low, high): pivot = arr[high] i = low - 1 for j = low to high - 1: if arr[j] < pivot: i++ swap arr[i] and arr[j] swap arr[i + 1] and arr[high] return i + 1
