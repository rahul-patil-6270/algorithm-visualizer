📘 What is Interpolation Search?

Interpolation Search is an improved variant of Binary Search. It works better on uniformly distributed arrays by estimating the likely position of the target value using a mathematical formula.

🧠 Algorithm:

low = 0, high = n - 1
while low ≤ high and x ≥ arr[low] and x ≤ arr[high]:
    pos = low + ((x - arr[low]) * (high - low)) / (arr[high] - arr[low])
    if arr[pos] == x:
        return pos
    elif arr[pos] < x:
        low = pos + 1
    else:
        high = pos - 1
return -1
