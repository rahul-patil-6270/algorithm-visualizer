Linked List

Definition: A linear data structure where each element points to the next.

Importance: Efficient insertions/deletions without shifting elements.

Applications: Dynamic memory allocation, real-time computing, undo mechanisms.

Types: Singly, Doubly, Circular.

Singly Linked List

Each node points to the next. Used in stacks, queues.

Doubly Linked List

Each node points to both next and previous. Ideal for bidirectional traversal.

Circular Linked List

Last node points back to head. Useful for looping structures like buffers.
