Merge Sort

Definition: Merge Sort is a divide and conquer sorting algorithm that:
1. Divides the input array into two halves,
2. Recursively sorts both halves,
3. And then merges the sorted halves into one final sorted array.

Importance: Efficient for large datasets with time complexity O(n log n) in worst, best, and average cases. Stable Sort – maintains the relative order of equal elements. Works well for external sorting and linked lists.

Real-life use:
1. Sorting large files on disk
2. Sorting linked lists
3. Multi-threading operations
4. SQL merge operations
5. Git branch merging



Algorithm (Pseudocode):

function mergeSort(arr):
    if length of arr ≤ 1:
        return arr

    mid = length of arr / 2
    left = mergeSort(arr[0..mid])
    right = mergeSort(arr[mid+1..end])

    return merge(left, right)

function merge(left, right):
    result = []
    while left and right are not empty:
        if left[0] ≤ right[0]:
            result.append(left[0])
            remove left[0]
        else:
            result.append(right[0])
            remove right[0]
    append remaining elements of left and right to result
    return result

Explanation:
1. Divide: Recursively split the array into halves until each sub-array has one element.
2. Conquer: Sort each half by recursively calling mergeSort.
3. Merge: Combine the sorted halves back together into one sorted array.
This process ensures that smaller problems are solved first, and then merged, achieving efficient sorting.
